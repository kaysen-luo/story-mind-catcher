# 📖 Story Mind Catcher · 小说架构编辑器

> 把脑子里散落的故事碎片，接住、归位、长成一部小说的骨架。

一个**纯前端、零后端、离线可用**的小说架构编辑器。数据只存在你自己的浏览器里，不上传、不追踪、不需要注册。

---

## ✨ 特性

- **三段式布局** —— 左侧目录树 / 中间表单 / 右侧实时档案预览，随时掌握全局
- **9 大板块** —— 立项、世界观、角色、冲突、表达、反面清单、章节…… 覆盖一部小说的架构骨架
- **碎片池** —— 每个板块独立的灵感暂存区，想到什么先扔进去，之后再归位
- **快速记一笔** —— 全局悬浮球，灵感来了随手写，自动归档到你指定的板块
- **多档管理** —— 同时推进多个故事，新建 / 切换 / 复制 / 重命名 / 删除
- **人物名片** —— 角色以卡片形式并列展示，含身份、简介、读者好感 / 作者投射双维度
- **Markdown 导出** —— 一键导出完整架构文档
- **PWA 离线可用** —— 可安装到桌面 / 手机主屏，断网照样写
- **本地优先存储** —— LocalStorage 主存 + IndexedDB 镜像备份，数据永远在你手上

---

## 🚀 使用

**在线版**：部署后补充链接

**本地运行**：

```bash
npm install
npm run dev      # 开发模式 → http://localhost:5173
npm run build    # 生产构建 → dist/
npm run preview  # 预览构建产物
```

单文件版本：项目根目录的 `index.html` 是不依赖任何构建工具的独立版本，双击即可打开使用。

## 🛠 技术栈

| 层 | 选型 |
|---|---|
| 框架 | [Alpine.js](https://alpinejs.dev/) |
| 构建 | [Vite](https://vitejs.dev/) |
| 离线 | [vite-plugin-pwa](https://vite-pwa-org.netlify.app/) (Workbox) |
| 存储 | LocalStorage + [Dexie.js](https://dexie.org/) (IndexedDB) |
| 部署 | Cloudflare Pages |

无后端、无数据库、无账号体系。
